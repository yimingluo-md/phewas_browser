IEI PheWAS Browser — Windows 10/11
==================================

1. Extract the ZIP completely.
2. Double-click "Launch IEI PheWAS Browser.bat".
3. Your web browser opens automatically. No Python installation,
   administrator access, or internet connection is required.

Windows may show a Microsoft Defender SmartScreen warning the first time. If
your institution permits this research tool, click More info, then Run anyway.

A minimized server window remains open while you use the browser. Close that
window, or double-click "Stop IEI PheWAS Browser.bat", when finished.

Keep the entire extracted folder together. Do not run the launcher from inside
the ZIP file.

through an approved secure institutional channel.
