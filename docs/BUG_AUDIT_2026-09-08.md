# Post-migration bug audit — 2026-09-08

Reviewed the core importer and query layer, API v1 and import jobs, TypeScript UI,
Tauri shell, CLI, migration checker, and CI/release configuration at `c3ec200`.
The working tree was clean at the start. Fixes below are local, uncommitted changes.
All imports, rename/remove operations, and browser tests used temporary synthetic
libraries. The existing real databases were opened read-only for comparison.

## Confirmed problems and fixes

| Area | Problem | Result after the fix |
|---|---|---|
| Static serving | An unauthenticated encoded `..` URL or a symlink inside the frontend could expose files outside it. | Resolve paths and reject anything outside the frontend root. Regression checks both cases. |
| CLI | `phewas serve` still targeted the deleted `app.py`, and refused an empty library. | Launch the current server with the selected library, a tokenized URL, and optional `--no-open`; empty libraries support first import. |
| CSV import | CSV headers were detected with commas, but preview/staging reused the tab delimiter. | Use the detected delimiter consistently. |
| Long input | A file containing the documented required columns failed because every optional statistic was referenced in SQL. | Only stage statistics present in the header; missing values remain NULL. Tests import both CSV and TSV with only the required columns. |
| Import paths | An apostrophe in the library path broke interpolated DuckDB settings. | Parameterize settings and escape SQL literals in configurable names. |
| Cancellation and cleanup | Cancellation during source hashing was ignored; failed imports attempted to delete an open DuckDB file. | Check cancellation during hashing and before publication, close the connection before cleanup, and record the exception in the failed-import log. |
| Library writes | Concurrent operations on the server's Library instance raced over `registry.json.tmp` and read-modify-write updates. Repeated reorder IDs duplicated entries. | Serialize operations with a reentrant lock and deduplicate ordering. A concurrent-registration regression retains all 12 datasets. |
| Rename | Refreshing a name/notes edit closed the cached database while other requests could still use it. | Reload only the editable manifest. An existing Dataset reference stays usable. |
| Navigation and plots | A delayed response could overwrite a newer route; a delayed Plotly import could target the wrong page. | Give each route a distinct element, discard results for detached pages, and bind plotting to its original element. |
| Import form | Inspection callbacks accessed removed controls; stale responses could validate a newer path. | Guard the form's lifetime and input values; disable Start while validation is pending. Handle Windows path separators too. |
| Progress client | A dropped SSE stream resolved with a still-running job, displaying failure and stopping progress. Navigating away caused callbacks to access missing controls. | Poll until a terminal state after stream failure; abort subscriptions on navigation and guard page updates. |
| Progress server | A keepalive suspended the generator while holding the job condition lock, blocking new progress when a client stopped consuming. | Yield outside the lock. A paused-consumer regression verifies the producer can continue. |
| Cancel/retry | “Start again” linked to the already-current import hash, so no navigation happened. | Explicitly render a fresh form. |
| Search | Slow results for an earlier query replaced the latest results. Header rerenders accumulated document click listeners. | Ignore stale results, clear old selections, and keep one outside-click listener. |
| Authentication | Storage failure discarded the launch token before the first API request. | Retain the launch token in memory as well as attempting storage. |
| Windows watchdog | ctypes used its default integer return type for a pointer-sized process handle. | Declare the Windows function signatures. A regression reproduces truncation with a 64-bit handle. |
| Desktop startup | The timeout was only checked when the child emitted output; a silent process left the spinner indefinitely. | Run the timeout independently and terminate a child that misses it. |
| Desktop data folder | The native menu opened Tauri's identifier-based folder instead of the Python library. | The ready handshake reports the actual library directory; the menu opens that path, including custom homes. Tauri's folder convention is documented in the [path API](https://v2.tauri.app/reference/javascript/api/namespacepath/). |
| Migration checker | SQL NULL comparison semantics hid numeric values lost to NULL, allowing a false “identical” result. | Treat an unknown equality result as a mismatch. A test deliberately removes populated CADD values and verifies failure. |
| CI and documentation | The browser smoke script existed but was no longer run by CI; contributor commands referenced deleted launchers. | Run smoke and browser regressions in CI, add Windows to the Python matrix, and update setup instructions. |

## Validation

- **52 Python tests pass**, including 14 added regression cases and the strengthened legacy equivalence test.
- **Ruff and strict mypy pass**; `git diff --check` passes.
- **TypeScript check and Vite production build pass.**
- **Full Playwright smoke passes**: home, gene filtering/sorting, variant annotation and plot,
  cohort toggles, search, dataset details, library, file picker, import with annotation,
  rename, removal, and missing-token behavior; no captured console/page/HTTP errors.
- **Seven targeted browser regressions pass.** Each failed before its corresponding fix:
  stale search, disabled storage, stale navigation, leaving during inspection,
  dropped progress stream, leaving during progress, and retry after cancellation.
- **Tauri `cargo check --locked` passes** on macOS arm64 using the existing Cargo.lock.
- **PyInstaller build and frozen-sidecar integration pass** on macOS arm64: readiness,
  token escaping, actual library-path handshake, authentication, bundled HTML/JS,
  built-in profiles, complete synthetic annotation import, and dataset metadata.
- **Strengthened real-data comparison passes** against the existing legacy database:
  50 gene summaries, 43,257 variant summaries, the complete annotation comparison
  (51 fields per matched variant/gene pair), the rsID map, and primary association
  row counts (68,761,368). Association values match for all traits in **300 sampled
  variants across META, AoU, and UKBB**.

## Validation limits

The Rust shell was compile-checked; native menu/dialog behavior and packaged DMG/NSIS
installation were not exercised. Windows-specific ctypes behavior was reproduced in
a platform-independent regression, but this session did not execute the application
on Windows or Intel macOS. The updated GitHub Actions workflows have not been run remotely.
The real-data association comparison is sampled, not a comparison of every association.

The build still reports the existing large Plotly chunk warning. PyInstaller reports
an optional `duckdb.experimental`/NumPy collection warning; the frozen importer passes.
Pytest reports an upstream Starlette/AnyIO deprecation warning.
