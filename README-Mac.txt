IEI PheWAS Browser — Mac
========================

1. Extract the ZIP completely.
2. Double-click "IEI PheWAS Browser".
3. Your web browser opens automatically. No Python installation, Terminal
   commands, administrator access, or internet connection is required.

The first time only, macOS may say it cannot verify the developer. If so:

1. Click Done.
2. Open System Settings > Privacy & Security.
3. Scroll to Security and click Open Anyway for IEI PheWAS Browser.
4. Confirm by clicking Open.

To stop the local browser server, double-click
"Stop IEI PheWAS Browser.command". Closing the web-browser tab alone does not
stop it.

Keep the entire extracted folder together. Do not run the app from inside the
ZIP file.
